# Diagramas de DataCircular

Archivos nuevos, generados a partir de los entregables finales y del árbol integrado del proyecto. No modifican el código ni los documentos existentes.

- `grafo_conexiones.json`: árbol de grupos, nodos y aristas.
- `grafo_conexiones.mmd`: grafo en Mermaid.
- `grafo_conexiones.dot`: grafo en Graphviz DOT.
- `grafo_conexiones.png`: imagen insertada en el Documento 10.
- `bpmn_desarrollo.png`: BPMN del proceso de desarrollo.

Las imágenes se generaron solo con hechos documentados o verificados por lectura del árbol integrado. El despliegue evidenciado es staging y la recepción institucional no está comprobada.
